# Laboratório de aprendizado Google Pub/Sub

> Para rodar o projeto é necessário exportar duas variáveis do projeto:

```shell
export PUBSUB_PROJECT_ID=ecommerce-messaging-lab
export PUBSUB_EMULATOR_HOST=localhost:8085
```

> Para verificar a exportação rode:

```shell
printenv PUBSUB_PROJECT_ID
printenv PUBSUB_EMULATOR_HOST
```
